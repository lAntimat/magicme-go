# go.magicmebook.ru

Страница-переходник для ссылки в профиле Instagram. Встроенный браузер Instagram в России работает только с VPN, а magicmebook.ru с VPN часто не открывается. Страница:

- в Instagram на Android сама открывает сайт в Chrome (`intent://`);
- в Instagram на iPhone показывает, как открыть во внешнем браузере, и даёт скопировать ссылку;
- в обычном браузере проверяет, отвечает ли сайт, и переходит на него, а если нет — советует отключить VPN.

Без внешних скриптов, шрифтов и аналитики; переход и копирование ссылки размечены `utm_source=instagram&utm_medium=social&utm_campaign=go`. Значение `social` поддерживается обработкой аналитики основного сайта. При недоступном буфере обмена показывается полный адрес с теми же метками.

Входящие параметры (`fbclid`, `igshid` и другие) не переносятся: основной сайт не использует эти идентификаторы для атрибуции, а неизвестные параметры блокируют загрузку внешнего счётчика. Источник Instagram задаётся метками самой страницы-переходника.
