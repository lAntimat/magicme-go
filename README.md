# go.magicmebook.ru

Страница-переходник для ссылки в профиле Instagram. Встроенный браузер Instagram в России работает только с VPN, а magicmebook.ru с VPN часто не открывается. Страница:

- в Instagram на Android сама открывает сайт в Chrome (`intent://`);
- в Instagram на iPhone показывает, как открыть во внешнем браузере, и даёт скопировать ссылку;
- в обычном браузере проверяет, отвечает ли сайт, и переходит на него, а если нет — советует отключить VPN.

Страница работает без внешних скриптов и шрифтов. Переход и копирование ссылки используют метки `utm_source=instagram&utm_medium=social&utm_campaign=go`. Значение `social` поддерживается обработкой аналитики основного сайта. При недоступном буфере обмена показывается полный адрес с теми же метками.

Входящие параметры (`fbclid`, `igshid` и другие) не переносятся: основной сайт не использует эти идентификаторы для атрибуции, а неизвестные параметры блокируют загрузку внешнего счётчика. Источник Instagram задаётся метками самой страницы-переходника.

## Статистика

Страница отправляет открытие `go` (`go_open`), нажатие кнопки открытия (`go_click_open`) и нажатие кнопки копирования (`go_click_copy`) в `POST https://magicmebook.ru/site-api/go-activity`. Тело запроса содержит только название события в формате `text/plain`. Браузер отправляет запрос без cookie и referrer. Переход и копирование работают без ожидания ответа. При недоступности API событие может потеряться. Основной сайт отдельно отмечает загрузку с метками `go`.

Перед публикацией страницы выпустите и проверьте API основного сайта с разрешённым источником `https://go.magicmebook.ru`. Для локальной проверки выполните `node --test`. Во временной копии `index.html` метатег `go-statistics-endpoint` можно заменить полным адресом тестового HTTPS API.
